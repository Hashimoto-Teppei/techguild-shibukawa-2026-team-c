# 公開 URL

QR で印刷・配布するので、**公開 URL は一度配ったら変えない**。

## 形

```
/m/:mapId                  マップページ（LP）
/m/:mapId?layer=:layerId   レイヤーを絞った状態で開く
```

- `mapId` はマップ作成時に自動生成し、あとから変えない（例: `/m/k3x9p2`）。デモ用データだけ読みやすい固定値にしてよい
- `layer` はレイヤー名ではなく ID で持つ。名前を直しても配った QR は壊れない
- 組織名・自治体名は URL に入れない

## 配った URL を壊さない

- 存在しないレイヤーを指していたら、全レイヤー表示にフォールバックする
- 削除・非公開のマップは「このマップは公開終了しました」ページを出す

## 配布しない URL

`/admin/*`（管理画面）と `/api/*`（API）は自由に変えてよい。

## 未決

- ドメイン: デモは `*.workers.dev`。ハッカソン後に運用するなら、印刷前に独自ドメインを決める
- スポット単体の URL は作らない。必要になったら追加する（既存の QR は壊れない）
