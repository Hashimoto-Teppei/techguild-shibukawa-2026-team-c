# デモデータ・橋本さんへの引き継ぎ

この表は、一般社団法人渋川マリンアクティビティ協会に向けた大会デモマップを含む**ローカルデモ seed 案**です。本番 D1 用データではありません。

## 表の見方

- `Maps`〜`Values`: ローカルデモ用。`beach-sports-demo` が大会用の独立マップ
- 大会マップの seed は `db/seed.sql` に追加済み。`mise run db:reset` でローカルに作り直せます
- `Event Prep`: 協会との相談用チェックリスト。DB seed に含めない
- `Seed Handoff`: DB スキーマへの列対応、除外列、投入範囲
- `source_url` / `verified_date` / `demo_note` / `verification_note`: 引き継ぎ用メタデータ。DB 列ではない

## 大会デモマップ

「渋川ビーチスポーツ大会（デモ）」を Event Prep の段取りごとに見られる4レイヤーに整理し、7つのスポットに分けました。

- **参加者向け（仮）**: 大会概要、種目・対象、申込・定員・参加費、持ち物、中止連絡。トイレ・駐車場・休憩などは該当施設のスポットにも分けて案内
- **会場・周辺設備**: 渋川海岸、渋川公園のトイレ、渋川観光駐車場、給水・休憩・更衣の確認先
- **開催準備・当日運営（検討用）**: 利用許可、会場区画と一般利用者との調整、受付・参加者管理、用具の固定・設営撤去、掲示・ごみ
- **安全・救護（検討用）**: 救護・AED・緊急車両動線、気象・海況・暑さの中止基準、保険・同意・未成年者対応

Event Prep 13項目を、参加者案内・施設確認・開催準備・安全対応へ割り当てました。渋川公園のトイレと市営駐車場は施設ごとのスポットに分け、確認済みの通常情報とイベント時の未確認事項を同じ項目で区別しています。受付や救護など位置未定の運営スポットは候補地付近の仮ピンで、実際の配置を示しません。大会は架空で、開催決定・参加募集ではありません。未確認情報はすべて仮置きです。

所有者はローカルデモの既存アカウント `user-kanko` です。協会の実ユーザーは作成していないため、協会が作成・承認したマップとしては案内しません。

## 確認済み情報と要確認事項

渋川公園のトイレ情報と、渋川観光駐車場の通常料金・台数は公式案内を参照し、値に出典 URL と確認日を記録しています。ただし、イベント会場からの距離、当日の利用可否・空き、シャワー・更衣、給水、日陰、AED の位置、海岸利用手続きや中止基準は未確認です。協会・施設・管理者の確認前に本番公開へ流用しません。

## 橋本さんへの seed 化メモ

1. 大会マップは `db/seed.sql` に反映済みです。`mise run db:reset` で作るローカルデモデータで、本番 D1 へ投入しないでください。
2. `owner_email` を既存ユーザー ID に対応付けます（現在の `db/seed.sql` では `kanko@example.com` → `user-kanko`、`other@example.com` → `user-other`）。大会デモマップも既存の `user-kanko` が所有するローカルデモです。
3. Maps の表示名・画像欄・source URL・作業メモ、Spots の source URL・確認メモ、Values の source URL・確認日は SQL 列に含めません。
4. 掲載期間は `YYYY-MM-DD` の文字列で保存します。日時に変換せず、日本時間・開始日と終了日を含む仕様に合わせます。
5. `Event Prep` は seed 対象外。`demo-cafe`、`tamano-walk`、`spot-event`、`beach-sports-demo` とスポーツ情報の仮置き値はローカルデモ限定です。
6. 実際に来訪者へ出すデータは別途、協会と管理者が開催許可・位置・設備・料金・安全情報を確認してから整備します。
