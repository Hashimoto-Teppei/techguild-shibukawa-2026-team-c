# デモ台本・操作手順

一般社団法人渋川マリンアクティビティ協会の皆さまに、閲覧者が大会案内を見て、作成者が自分でマップを作る流れを紹介する。通しの操作デモは約5分。7分発表に入れる場合は、後半の「短縮版」を使う。

## 発表前の準備

- ブラウザーに公開ページと管理画面の2タブを用意する。公開側は `/`、管理側は `/admin/login` を開く。
- 登録とマップ作成の操作はローカル環境で通し練習する。`mise run db:reset` の後に `mise run dev` を起動し、`http://localhost:5173` を使う。デモ用ログインは `kanko@example.com` / `demo-pass-1234`。
- 新規登録も実演する場合は、ローカルで未使用のメールアドレスを使う。登録後に一度ログアウトして、同じアカウントでログインするところまで練習しておく。
- 本番 URL では橋本さんが用意した発表用アカウントを使う。本番での新規アカウント作成や新規マップ公開は、データが残るため事前に担当者と相談する。ローカルの `db:reset` は実行しない。
- 大会マップは架空の説明用データ。募集や開催決定ではないこと、仮ピンは運営配置を示さないことを最初と最後に伝える。

## 台本と画面操作

### 1. ログイン・新規登録（約50秒）

**操作**

1. 管理側タブで `/admin/login` を表示する。
2. メールアドレス・パスワード欄と「ログイン」「新規登録」ボタンを見せる。
3. ローカルで未使用の発表用メールアドレスと8文字以上のパスワードを入力して「新規登録」を押す。
4. `/admin` に移動したら「自分のマップ」画面を見せ、「ログアウト」を押す。
5. 同じメールアドレス・パスワードで再度ログインし、管理画面へ戻る。

**話すこと**

> マップを作る人は、メールアドレスとパスワードで登録して、自分のマップを管理します。登録後はそのまま管理画面に進みます。マップを見るだけの人は、登録もログインも必要ありません。

現行デモでは表示名入力・確認メールはなく、登録したメールアドレスがアカウント名になります。パスワードは8文字以上です。

### 2. サービスのイメージ（約40秒）

**操作**

1. 公開側タブで `/` を表示する。
2. ファーストビューの「公開中のマップを見る」からマップ一覧へ移動する。
3. 一覧にある公開マップカードと、画面下の「お店や団体のマップを作れます」を見せる。

**話すこと**

> たまりんマップは、地域のお店や団体などが、自分たちのおすすめや案内を地図にまとめて公開するサービスです。閲覧者はログインせずにマップを開けます。目的別のレイヤーで情報を切り替え、スポットの詳細や経路を確認できます。公開したマップは QR でも案内できます。

### 3. 大会デモマップ紹介（約90秒）

**操作**

1. マップ一覧から「渋川ビーチスポーツ大会（デモ）」を開く。
2. 「参加者向け（仮）」を選び、大会スポットの申込・持ち物・開催日時が未定であること、中止連絡の考え方を見る。
3. 「会場・周辺設備」に切り替え、渋川公園のトイレ、渋川観光駐車場、給水・休憩・更衣の確認スポットを順に開く。
4. トイレ・駐車場の通常情報と、当日利用・経路・空きなどの要確認事項を区別して見せる。
5. 「開催準備・当日運営（検討用）」で許可・会場区画・一般利用者との動線・用具・受付を、「安全・救護（検討用）」で救護・AED・中止基準・保険を見せる。

**話すこと**

> 協会の皆さまとの開催準備を想定し、Event Prep の確認項目を、参加者向け、会場設備、開催準備、安全救護の4つに分けました。たとえばトイレや駐車場は施設ごとに確認でき、通常の施設情報と大会当日の条件を分けてあります。受付・救護など位置が決まっていない項目は仮ピンで、実際の配置ではありません。大会自体も架空で、開催・募集情報ではありません。

### 4. マップ作成手順（約2分）

**操作**

1. 管理画面 `/admin` に戻り、「自分のマップ」の名前欄に「ビーチスポーツ体験会の案内（作成デモ）」と入力して「作成」を押す。
2. 新しいマップが非公開で作成され、編集画面が開くことを見せる。
3. 「マップページの見た目」で説明文を入力して「タイトルと説明文を保存」。ヘッダー画像は時間があればアップロードする（JPEG・PNG・WebP、10MBまで）。
4. 「レイヤー」で「参加者向け」を追加し、その下の「項目を追加」から「持ち物」「トイレ」「中止連絡」を登録する。
5. 「スポットを追加」を押し、名前・説明を入力。表示するレイヤーで「参加者向け」を選び、項目の値を入力する。
6. 地図をクリックしてピンを置き、必要ならドラッグで調整する。期間限定にする場合だけ掲載開始日・終了日を設定して保存する。
7. 「公開する」を押し、「公開ページを開く」で閲覧者側の見え方を確認する。

**話すこと**

> 作成の流れは、マップの名前と説明を用意し、目的別レイヤーと表示項目を作り、地図上にスポットを置く、という順番です。スポットは複数のレイヤーに登録できます。掲載期間を設定したスポットは、期間を過ぎると公開ページに表示されなくなります。内容を確認してから公開すれば、閲覧者がログインなしで見られるようになります。

実演では1レイヤー・1スポットまでに絞る。大会用の4レイヤー・7スポットを一から作る操作は、Event Prep の反映先を見せて説明する。

## 7分発表用の短縮版

登録・ログインは管理画面で「新規登録」ボタンと既存デモアカウントのログインを見せ、登録操作自体は省略する。サービスイメージはトップ画面で一言、大会マップは参加者向け・会場設備・安全救護から各1スポット、マップ作成は「マップ作成→レイヤー→スポット→公開」の順に操作する。時間が足りない場合は、スポット入力済みの非公開マップを用意して、公開操作と公開ページの確認を見せる。

## デモ当日の注意

- 本番 URL で使う発表用アカウントとパスワードは橋本さんに確認する。リポジトリ記載のローカル用パスワードを本番で使わない。
- 登録・マップ作成を本番で行うとデータが残る。実演する場合は発表用アカウントとデモ用マップを事前に用意し、公開状態を担当者と確認する。
- 登録後は自動で `/admin` に移動する。ログイン・登録画面は `/admin/login`、公開マップ一覧は `/`。
- 新規作成したマップは最初は非公開。公開前にタイトル、説明、スポットの位置と値を確認する。
- 大会日程、参加募集、利用許可、当日の設備・安全条件は仮置き。確定した案内として紹介しない。
- 公開 URL は `/m/beach-sports-demo?layer=participants`。QR を配布する場合は URL と読み取りを確認する。
