# ビジュアルデザイン

渋川海岸（ビーチスポーツの聖地、瀬戸内海）の浜辺を題材にする。主役は「島影のある水平線と波」で、ほかの部分は静かに保つ。画面を足すときもこの方針に合わせる。

## 色

`src/client/styles.css` の `:root` にトークンとして定義し、Tailwind では `bg-sea` / `text-ink` のように使う。shadcn/ui の `--primary` などの変数も、このトークンに対応づけてある。

| トークン | 値 | 役割 |
|---|---|---|
| `ink`（瀬戸の藍） | `#0b2e4f` | 文字、暗い背景。黒の代わりに使う |
| `sea`（海） | `#0e7fb8` | 地図のピン、海、リンク |
| `lagoon`（ラグーン） | `#3cc8d6` | 波 |
| `sand`（砂） | `#ead3a2` | 面（画像がないときのカード、項目欄、下部の案内） |
| `buoy`（ブイ） | `#ffc72c` | **選択中**と**主ボタン**だけに使う（レイヤーの丸、経路ボタン、選択中のピン） |
| `foam`（泡） | `#f3f9fa` | ページの背景 |

- ダークモードは作らない
- motion は `var()` を補間できない。そのため `map-view.tsx`（ピンの色）と `day-sky.tsx`（時刻ごとの色）には 16 進数を直書きしている。発表スライドの `slides/uno.config.ts` も同じ値を持つ。トークンを変えたら、ここも合わせて変える

## 書体と形

- 見出し: Dela Gothic One（`font-heading`）。太さは 1 種類だけなので、`font-bold` は付けない
- 本文: 端末のフォント（`system-ui` / ヒラギノ / Noto Sans JP）
- 角丸: カード・地図・詳細などの大きな面は `rounded-panel`（1.75rem）、ボタンとチップは `rounded-full`
- 暗い背景（藍の上）の領域には `on-dark` クラスを付ける。キーボードのフォーカス枠がブイ色になる（明るい背景では藍）

## 動き

`motion`（motion/react）を使う。動きは次の 2 種類に絞る。

- **一度だけの演出**: トップの読み込み時の「海がせり上がり、見出しが立ち上がる」と、1 日の空
- **操作への応答**: レイヤーの丸がスライドする（`layoutId`）、スポット詳細がばねで開く、カードにカーソルを乗せると写真が拡大する

セクションごとのフェードインのような、飾りのための動きは足さない。

OS の「視差効果を減らす」設定に従う。

- `main.tsx` の `MotionConfig reducedMotion="user"` で、animate と layout の動きを止める
- スクロール連動の動き（パララックス）とスムーズスクロールは、`useReducedMotion()` で個別に止める
- CSS アニメーション（`.wave-drift` / `.twinkle`）は、`styles.css` のメディアクエリで止める

## 部品

- `components/public/wave.tsx`: 横に流れる波の帯。色は `text-*`、高さは `h-*`、速さは `speed` で指定する。セクションの境目を波で切りたいときに使う
- `components/public/day-sky.tsx`: トップの背景（下記）

## トップの「渋川の1日」

40 秒で 1 日を一周する（`DAY_SECONDS`）。空・太陽・月・星・島・海・波の色は、すべて時刻 `t`（0〜1）から決まる。

| t | 時刻 | 景色 |
|---|---|---|
| 0 | 5:00 | 夜明け。左の水平線から日が昇る |
| 0〜0.64 | 5:00〜19:00 | 太陽が弧を描いて渡る。低いときは海面にきらめきが映る |
| 0.64 | 19:00 | 日の入り。空は紫からオレンジ、波は夕日の色になる |
| 0.68〜1 | 夜 | 星がまたたき、島に町の灯りがともる。月が昇り、海に月の光が映る |

- 画面に作中の時刻を出す。演出用なので、スクリーンリーダーには読ませない
- 画面外にスクロールしたら時間を止める（`useInView`）。視差効果を減らす設定のときは、昼（t = 0.3）で止める
- 時間帯を足す・色を変えるときは、`src/shared/day-sky.ts` の `STOPS` と各色の配列を同じ並びで直す（発表スライドの背景も同じ定数を使う）
- ヒーローは画面いっぱいの高さ（`min-h-svh`）にする。太陽と月が見出しの下の空を通るようにするためで、マップ一覧へは「公開中のマップを見る」ボタンで降りる

## 読みやすさ

- 動く空の上に置く文字は白 100% にする（どの時刻でも WCAG AA を満たす）。白の半透明は使わない
- 写真の上の文字は、下側に藍のグラデーションを敷くか、`bg-ink/70` 以上の下地に載せる
- タップする部分は高さ 44px 以上

## 速さ

- 和文の Web フォントは、CSS だけで数百 KB になり、最初の表示を遅らせる。本文には使わない。見出しのフォントは `src/client/fonts.css` に分け、`main.tsx` から後で読み込む
- 動いている要素の上に `backdrop-blur` を重ねない

## 文言

- 公開ページは標準語（県外の観光客も読む）
- 作成者画面は岡山弁（`docs/ui-ux.md`）

## やらないこと

- 地図タイルの配色変更（今の `DEMO_MAP_ID` ではできない。やるなら Cloud Console で Map ID を作る）
- 公開側のボタンを shadcn/ui の `Button` にまとめる（今は手書きのクラス。必要になったら `variant` を足す）
