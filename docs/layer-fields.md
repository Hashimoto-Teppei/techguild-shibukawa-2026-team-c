# レイヤーの項目

スポットに位置・名前・説明以外の補足情報を載せるため、レイヤーごとに**項目**を定義できるようにする（例: 「家族向け」に「授乳室」「駐車場」「ベビーカー」）。用語は `GLOSSARY.md`。

## 決めたこと

- 項目はレイヤーに定義する。スポットには、属するレイヤーすべての項目を合わせて出す
- **項目の値**はスポットと項目の組に1つ。レイヤーごとに別の値は持たない
- 項目は型を持つが、今は「テキスト」だけ。型の選択欄は出さない。値は常にテキストで保存し、型を足すときは入力欄と表示を分岐させるだけでデータ移行はいらない
- 項目名は空にできない。同じレイヤー内・別レイヤー間で同名でもよい
- 並び順はレイヤーの並び順 → 項目の作成順。並べ替え UI は作らない
- スポットをレイヤーから外しても値は残す（表示も入力欄も出さない）。入れ直せば戻る
- 項目を削除したら値も消す。レイヤーを削除したら項目と値も消す

## 画面

- 管理: マップ編集画面のレイヤーごとに、項目の追加・名前変更・削除。削除時は「入力済みの値も消えます」と確認を出す。レイヤー削除の確認文も項目と値が消えることを伝える
- 管理: スポット編集フォームで値を1行テキストで入力。レイヤー名を見出しにして項目をまとめ、所属レイヤーのチェックに合わせて入力欄がその場で増減する
- 公開: スポット詳細に「項目名: 値」を見出しなしで並べる。空の値は出さない。選択中のレイヤーに関係なく、属するレイヤーすべての項目を出す

## API

- 値の保存は、送られた項目だけを上書きする（送られていない項目には触らない）。空文字で保存すると値なしになる。これで「レイヤーから外しても値を残す」を実現する
- 値を保存するときは、項目がスポットと同じマップのものか確かめる。項目の API はレイヤー → マップの `ownerId` で絞る
- 公開 API は、スポットがいま属しているレイヤーの項目の値だけを返す（外したレイヤーの値を見せない）

## 作らない

- 値での絞り込み・検索（絞り込みはレイヤー切替が担う）
- テキスト以外の型
