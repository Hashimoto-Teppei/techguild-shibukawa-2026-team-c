## PC の左右レイアウト

PC 幅（1024px 以上）で左右の余白が空いていたので、幅を活かす。スマホは今の縦並びのまま（QR で開くのはほぼスマホ）。

- マップページ: 左にスポット一覧、右に地図（画面に貼り付け、一覧だけがスクロールする）。スポットを選ぶと、一覧のその行の直下に詳細が開く。ピンを押すとその行までスクロールする
- 一覧の行には説明文の1行目を出す（スマホも同じ）
- 編集画面: 見た目とレイヤーのカードを横に並べ、スポットのフォームは左に入力欄、右に地図
- 非公開のマップでは「公開する」を主ボタン（ブイ色）にする
- 作らない: 一覧にマウスを乗せたときのピンの強調（必要になったら足す）
