# 画面・機能の範囲と担当分け

デモシナリオ（`docs/demo-scenario.md`）に出てくるものを作る。出てこないものは作らない。

## 画面

### 公開側（閲覧者・ログイン不要）

- `/`: 公開中（`published = true`）のマップ一覧を新しい順で（タイトル・ヘッダー画像のカード）
- `/m/:mapId`: ヘッダー画像・タイトル・説明文、地図とスポットのピン、レイヤー切替
- スポット詳細（経路ボタンつき、項目の値）。掲載期間外のスポットは出さない
- 非公開ページ（存在しない・非公開のマップ。作成者本人でもプレビューはできない）

### 管理側（作成者）

- `/admin/login`: ログイン・サインアップ
- `/admin`: 自分のマップ一覧、新規作成（新規は非公開）
- `/admin/maps/:id`: マップ編集。公開/非公開の切替、LP 設定（タイトル・説明文・ヘッダー画像）、レイヤーとその項目の追加・名前変更・削除、スポット一覧
- スポット編集: 名前、説明、所属レイヤー（チェックボックス）、項目の値、掲載期間（任意。入れると臨時スポット）。位置は地図をクリックしてピンを置き、ドラッグで調整する
- `/admin/maps/:id/qr`: レイヤーを選んで QR を出し、印刷用レイアウトで表示。非公開マップでも発行でき、「非公開です」と1行注意を出す

### データ

`maps`（`owner_id` と `published` を持つ）/ `layers` / `spots` / `spot_layers`（多対多）/ 項目と項目の値（`docs/layer-fields.md`）/ BetterAuth のテーブル

`/admin/maps/:id` 配下と、マップ・レイヤー・スポット・画像アップロードの API はすべて `owner_id` を照合し、他人のマップは 404 を返す

### 作らない

- アカウント管理画面・パスワードリセット・メール認証
- 共同編集（マップは作成者1人のもの）
- 公開マップ一覧の検索・並び替え
- 通報・モデレーション（誰でも公開できるが、ハッカソンでは対策しない。今後の課題）
- スポットの画像（LP のヘッダー画像のみ）
- LP のセクション構成の自由編集（時間が余れば）
- 住所検索（ピンを置く方式で足りる）

## 進め方

- 橋本が先に雛形を作り、部品の置き場所と仮データを用意する
- メンバー1・2 は仮データを props で受け取って表示する部品だけを作る。DB・API には触らない
- 担当ごとにファイルを分けてコンフリクトを避ける
- 担当ごとのブランチから PR を出し、橋本がマージする。Claude Code などの AI を使ってよい
