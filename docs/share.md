# シェアと OGP・SEO

閲覧者がマップを SNS などで**シェア**できるようにし、貼ったリンクにそのマップのカードが出るようにする。

## シェアボタン

- 置くのは `/m/:mapId` だけ。ヘッダー右上の「シェア」から、スマホは下から出るシート、PC は中央のダイアログを開く（`<dialog>`）
- シートは絵はがき風: 上にヘッダー画像・マップ名・送るレイヤー、下に「X でポスト」「LINE で送る」、URL とコピー、切手風の QR（目の前の人に読み取ってもらう用）
- シェアする URL は今見ている状態: `/m/:mapId`、レイヤーを絞っていれば `?layer=:layerId` も付ける（スポットは入れない）
- 本文はマップ名と URL だけ。ハッシュタグは付けない
- 公開ページなので文言は標準語
- 作らない: Web Share API（端末ごとに見え方が違う）、流入の計測（必要なら後から `utm` を足す。配った URL は壊れない）

## OGP（リンクのカード）

Worker が `/` と `/m/:mapId` の HTML を返すときに、`<head>` のメタタグを書き換える（`run_worker_first`）。

- タイトル: `{マップ名} | たまりんマップ`
- 説明: 説明文の先頭120字。空ならサービス共通の文
- 画像: ヘッダー画像。なければ `public/og.png`（1200×630）
- `twitter:card` は `summary_large_image`。`?layer=` 付きでもカードはマップ単位で同じ

## SEO

- canonical は `/m/:mapId`（`?layer=` を外す）
- 非公開・存在しないマップは `noindex` を付け、ステータスを 404 にする
- `/robots.txt`: `/admin/` と `/api/` を Disallow にし、sitemap の場所を書く
- `/sitemap.xml`: `/` と公開中のマップ
- 作らない: SSR・プリレンダー（本文は Google が JS を実行して読む）、構造化データ
